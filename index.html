개인정보처리방침

최종 업데이트: 2026년 10월 16일

Static Screen Recorder(이하 “앱”)는 사용자가 기기 화면을 녹화할 수 있도록 돕는 앱입니다. 본 개인정보처리방침은 앱이 정보를 처리하는 방식을 설명합니다.

수집 및 공유하는 정보

앱은 개인정보를 수집하거나 서버 또는 제3자와 공유하지 않습니다. 광고, 분석 또는 추적 SDK를 사용하지 않습니다.

화면 녹화 및 오디오

앱은 사용자가 직접 화면 녹화를 시작하고 Android 시스템 권한 요청을 허용한 경우에만 화면과 선택한 오디오를 녹화합니다. 녹화된 영상과 오디오 파일은 사용자의 기기에만 저장되며, 앱이 외부 서버로 업로드하거나 전송하지 않습니다.

다른 앱 위에 표시

사용자가 선택한 경우, 앱은 다른 앱을 사용하는 중에도 녹화를 시작할 수 있도록 화면 위에 플로팅 녹화 시작 버튼을 표시할 수 있습니다. 이 기능은 사용자가 앱 설정 또는 플로팅 버튼의 닫기 기능으로 언제든지 중지할 수 있습니다.

알림

앱은 녹화 진행 상태와 플로팅 녹화 시작 버튼의 실행 상태를 알리기 위해 알림을 표시할 수 있습니다.

보안

녹화 파일은 사용자의 기기 저장공간에 보관됩니다. 기기 보안과 파일 관리 책임은 사용자에게 있습니다.

개인정보처리방침 변경

앱 기능 또는 관련 법령의 변경에 따라 본 방침을 수정할 수 있습니다. 변경 사항은 이 페이지에 게시합니다.
